# 📊 Digital Wellbeing Analysis

This project analyzes and visualizes **digital wellbeing data** (screen time, app usage, etc.) to provide insights into user habits and promote healthier digital usage.  
It combines **Python for data preprocessing & analysis** with **Power BI for interactive dashboards**.

---

### 📊 Possible Insights

1. **Screen Time Trends**

   * Average daily screen time (e.g., *4.5 hours/day*).
   * Weekly and monthly variations (e.g., *higher usage on weekends*).

2. **Most Used Apps**

   * Top apps by total usage (e.g., *Instagram & WhatsApp account for 60% of total time*).
   * Category-wise usage (e.g., *Social media > Entertainment > Productivity*).

3. **Peak Usage Hours**

   * Time of day with maximum activity (e.g., *8–10 PM is the most active period*).
   * Morning vs evening screen habits.

4. **Digital Balance**

   * % of productive vs. non-productive usage (e.g., *70% time on entertainment apps, 30% on productivity apps*).
   * Recommendations for rebalancing habits.

5. **Anomalies & Spikes**

   * Days with unusually high screen time.
   * App binge patterns (e.g., *sudden spike in YouTube usage on weekends*).

6. **Comparisons**

   * Weekday vs. weekend usage difference.
   * Comparison between different apps/categories.

---

### 🎯 Summary Insight :

* *“Analysis revealed that social media apps (Instagram, WhatsApp) accounted for 55% of total usage, with peak activity during late evenings. Average daily screen time was 4.2 hours, showing a 25% increase on weekends compared to weekdays. This highlights opportunities to promote balanced digital habits.”*

## 🚀 Features
- Data preprocessing and cleaning using **Python (pandas, numpy, re)**  
- Exploratory data analysis and visualization using **matplotlib & seaborn**  
- **Power BI Dashboard** for interactive insights:
  - Daily & weekly screen time trends  
  - Most used apps and categories  
  - Usage distribution across platforms  
- Recommendations for improving digital wellbeing

- **Power BI**: Interactive dashboards
